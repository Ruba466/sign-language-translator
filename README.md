# 🧠 Sign Language Translation System

This project is focused on building an AI-powered **Sign Language Translation System** to recognize sign gestures in real-time and convert them into human-readable text/speech.

---

## 🚀 Project Objective

To bridge the communication gap between the deaf/hard-of-hearing community and others by leveraging **computer vision**, **deep learning**, and **gesture recognition**.
